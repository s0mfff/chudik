# ЧУДИК — web-deck

Финализированная web-версия инвестиционной презентации «ЧУДИК / Original IP Universe».

## Что внутри

- `index.html` — главная страница web-deck.
- `styles.css` — desktop/mobile оформление, clean-mode, print fallback.
- `script.js` — навигация, меню, свайпы, клавиатура, fullscreen, hash-ссылки.
- `assets/slides/` — 15 слайдов из PPTX в WebP.
- `assets/video/` — MP4-версии живых фрагментов персонажей:
  - `sonya-loop.mp4`
  - `chudik-loop.mp4`
  - `mama-loop.mp4`

## Как посмотреть локально

Откройте `index.html` в браузере.

Если нужен локальный сервер:

```bash
python3 -m http.server 8080
```

Затем открыть:

```text
http://localhost:8080
```

## Режим показа

- Стрелки ← / → — переключение слайдов.
- Space — следующий слайд.
- Home / End — первый / последний слайд.
- M — открыть / закрыть меню разделов.
- F — fullscreen.
- H — чистый режим без интерфейса.
- Свайп влево / вправо — переключение на телефоне.
- Кнопка `Разделы` — меню по слайдам.
- Кнопка `Во весь экран` — fullscreen на desktop.
- Кнопка `◐` — скрыть интерфейс для чистого показа.

## Прямые ссылки на слайды

Можно открыть сразу конкретный слайд:

```text
index.html#slide-04
index.html#slide-14
```

Для показа без стартового экрана:

```text
index.html?present=1#slide-01
```

## Важно

Если позже появится отдельный саундтрек, его можно подключить через стартовую кнопку `Начать показ`, потому что браузеры обычно блокируют автозапуск звука без первого клика пользователя.

Если заказчица предоставит лицензированные файлы фирменных шрифтов, их можно встроить через `@font-face`. Сейчас используются стабильные системные шрифтовые стеки, чтобы презентация не зависела от внешних сервисов.


## Музыка

Чтобы включить фоновую музыку:

1. Положите аудиофайл в папку `assets/audio/`.
2. Назовите файл строго `soundtrack.mp3`.
3. После нажатия кнопки «Начать показ» музыка стартует автоматически, потому что это пользовательское действие разрешает браузеру запуск аудио.
4. Начальная громкость специально тихая: `0.16` из максимума `1.0`.
5. В правом верхнем углу есть кнопка музыки и ползунок громкости. Максимум ползунка ограничен значением `0.6`, чтобы музыка случайно не включалась слишком громко.

Клавиша `U` включает/выключает музыку.
Клавиша `H` включает чистый режим показа. Кнопка чистого режима при этом остаётся видимой, чтобы можно было вернуть интерфейс.

## Mobile v8

Мобильная версия теперь работает как горизонтальная презентация, а не как скролл-лента.

- Desktop показывает полные слайды 16:9.
- Mobile показывает отдельный набор кадров:
  - слайд 01 целиком;
  - слайды 02-15 нарезаны на левую и правую половину;
  - геройские слайды 04-06 берутся из текущего web-deck дизайна, а не из PDF.
- Листание на телефоне: свайп влево/вправо или кнопки ‹ ›.
- Ссылка остаётся одна: браузер сам выбирает desktop/mobile по ширине экрана.



## Scroll feed / optimization v15

- «Разделы» расположен над кнопкой fullscreen.
- Навигационный прогресс вертикальный и находится справа от слайда.
- Прогресс показывает реальную позицию вертикального скролла.
- Видео-лупы загружаются с `preload="auto"` и после первой загрузки кэшируются в Blob URL на время сессии, поэтому при возврате к слайду не запрашиваются заново.
- Видео вне зоны просмотра ставятся на паузу, но источник не выгружается.
- Дальние слайды используют `content-visibility: auto`, изображения — lazy loading + async decoding.

### 60 FPS

Код готов для плавного воспроизведения 60 FPS, но реальная частота кадров определяется самим MP4. В переданном комплекте нет файлов `assets/video/sonya-loop.mp4`, `chudik-loop.mp4`, `mama-loop.mp4`, поэтому перекодировать их физически в 60 FPS в этой сборке невозможно. После добавления исходных MP4 их можно перекодировать без изменения HTML/JS и оставить те же имена файлов.
